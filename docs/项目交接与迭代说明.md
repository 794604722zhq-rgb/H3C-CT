# ZHQ 选型工具｜项目交接与迭代说明

更新时间：2026-08-24

## 1. 项目目标

本项目用于根据招标参数快速匹配新华三产品，当前包含：

- 新华三交换机选型助手
- 新华三无线产品选型助手
- 新华三路由器选型助手
- 小贝优选产品选型工具
- 最终版 Excel 的网页数据库查看器
- 部分交换机型号的招标引导、参数选择、排序和复制功能

统一入口为仓库根目录 `index.html`。

## 2. 目录与数据关系

- `index.html`：ZHQ 统一入口。
- `h3c-selector/`：新华三交换机、无线、路由器三个独立入口共用的选型引擎。
- `xiaobei-selector/`：小贝优选选型工具。
- `database-viewer/`：三个最终版 Excel 的网页查看器，支持全部工作表筛选。
- `database/`：交换机、无线、路由器最终版 Excel。
- `h3c-selector/data/`：网页选型使用的静态产品数据。
- `h3c-selector/guides/`：交换机招标引导页面及数据。

Excel 是人工维护和复核的数据底稿；网页使用静态 JavaScript 数据，Excel 更新后需要同步更新对应网页数据。

## 3. 已确认的关键匹配逻辑

### 通用逻辑

- 匹配结果先区分“符合、待确认、不符合”，再按参数接近程度排序。
- 满足条件的产品中，参数越接近需求，匹配度越高。
- 单位统一识别：`T = Tbps`、`G = Gbps`、`M = Mpps`、`1G = 1GE`。
- 端口速率以斜杠并列时按最高速率理解，例如 `10G/2.5G/1G` 按 10G，`25G/10G` 按 25G。
- 端口数量可省略“端口/光口”后缀，例如 `6个100G` 按 6 个 100G 端口识别；写明 `SFP+`、`SFP28`、`QSFP28` 等封装时，须按对应封装分别核算，不能用其他封装端口凑数。
- `1000BASE-X SFP` 与千兆光口等价，按 1G 光口及 SFP 封装识别。

### 交换机

- 千兆电口包含 `10/100/1000Mbps 自适应电口`、GE RJ45 等说法。
- 2.5G 电口包含 `100/1000/2500Mbps 自适应电口`。
- 千兆光口包含 SFP、SFP 千兆光口等说法；万兆光口包含 SFP+、SFP+ 万兆光口等说法。
- 框式交换机重点比较交换容量、包转发率、主控板数量、交换网板数量和业务板数量，忽略固定端口配置。
- RS 系列属于弱电款型，网页保留但降到最低推荐优先级。
- 非框式交换机需要维护完整端口形态；带扩展槽位的产品可展示官网选配页面中的可选组件。
- “以太全光影终端”产品默认不参与推荐，只有勾选“选用以太全光/影终端方案”后才开放该分类。
- PoE 交换机除供电等级外，还要按整机 PoE 供电功率区分；网页支持识别并筛选最低功率要求，未核实功率的型号只作“待核对”，不猜测数值。

### 无线

- AP 与 AC 控制器分开匹配。
- AP 支持按 Wi-Fi 6、Wi-Fi 7、产品形态、总流数、整机速率、端口和 PoE 条件筛选。

### 路由器

- 分为高端路由器、中低端框式、汇聚/接入路由器和中低端盒式路由器。
- 框式/模块化路由器忽略固定端口要求，重点比较交换容量、包转发率和板卡/线卡数量。
- 交换容量标注“官网未公布”时，不参与交换容量硬性淘汰，结果显示为待确认。

### 小贝优选

- 在其他条件完全一致时，价格更低的型号优先。

## 4. 招标引导逻辑

- 已有关联的产品型号在选型结果和网页数据库中显示“招标引导”按钮。
- 招标参数支持按“指标分类”和“参数类型”筛选。
- 切换筛选条件后，已经选择的参数必须保留；页面会显示当前筛选中已选数量及其他分类保留数量。
- 已选参数可拖动排序、上移、下移，并生成最终参数预览和复制文本。
- 最终复制文本只输出编号和详细技术参数，不输出分类标签。
- “竞品及补充资料”默认折叠；展开时清理源表中的 `11/12` 占位值，并隐藏整列没有有效内容的字段。
- “开放网格渠道（是/否）”字段已从所有网页招标引导数据库删除。

## 5. 网页数据库逻辑

- 三个数据库都支持切换具体工作表。
- “全部工作表（全库筛选）”可跨所有 Sheet 搜索型号、系列和参数。
- 全库结果统一展示来源工作表、产品型号、系列/形态、分类、参数摘要和官网来源。
- 对已有招标引导的型号显示跳转按钮。
- 页面保留“下载原始 Excel”按钮。

## 6. 版本同步约定

每次功能或数据更新都需要同时维护两份：

1. 本地使用版：`选型工具最终版` 文件夹。
2. Git 工作副本：本仓库对应目录。

发布前应至少检查：

- JavaScript 语法无错误。
- 交换机、无线、路由器三条产品线可正常匹配。
- 全库筛选和单 Sheet 搜索正常。
- 已有关联型号的招标引导按钮可以打开正确页面。
- 招标参数跨分类选择不会丢失。
- 本地最终版与 Git 工作副本的对应文件已同步。

只有用户明确提出“发布”或“同步到 Git”时，才提交并推送。

## 7. 新电脑或新账号继续维护

新环境接手时，建议先阅读本文件和 `README.md`，再检查最新 Git 提交。不要根据旧聊天印象直接覆盖数据。

完整聊天记录和模型内部思维过程不适合作为项目文件同步；本文件记录了可复用的需求背景、已确认规则、目录结构和维护方法。账号令牌、登录凭证和个人隐私不得写入仓库。

## 8. 数据准确性原则

- 产品参数优先以新华三中文官网公开数据为准。
- 官网没有公布的数据明确标记，不虚构精确数值。
- 用户提供的招标引导 Excel 是对应引导页面的内容来源。
- 发现官网、Excel 和网页数据不一致时，先列出差异并确认，再做批量修改。
